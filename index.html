Welcome to #MamaNyoSquad • LIVE!


This will serve as a directory to access the broadcast resources used during live streams.



Who will be using this repository?


This repository is mainly used by the SquadMates in order to enhance the broadcast experience, which is mainly events tied to DOAXVV and PRISM.


However, it may be used by anyone who wants to try the resources before using in their own streams. Documentation is provided in order to help with using such resources, added and updated over time.


Please know that in order to use these resources, you need to have a basic understanding of JavaScript functions. In addition, you will need OBS (or any streaming software) that supports browser sources -- configured to access the software's DevTools.


In order prepare your software, you may refer to the following documentation:




Stream resources


Relevant documentation about them are provided below each resource.


Lower Thirds

File: lowerThirds.html


Lower Thirds provide brief information about the stream, as well as news-like contents that briefly describe the stream's event.


The design language is based on BBC News' version of their lower thirds, with some modifications to the fonts and palette.



Breakfiller

File: breakfiller.html


THe Breakfiller provides a quick summary of the events that will be happening during the stream to keep viewers in the loop on what they can expect.


Although the animation language is based on BBC News' version due to the way the elements are animated, it employs its own design language that takes detail into account.
